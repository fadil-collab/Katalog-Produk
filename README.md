Katalog Produk — JavaFX & SQLite
Aplikasi desktop berbasis JavaFX dan SQLite untuk mengelola data katalog produk dengan fitur CRUD (Tambah, Lihat, Edit, dan Hapus produk).

Cara Menjalankan Aplikasi
Buka proyek KatalogProduk di Apache NetBeans IDE (File > Open Project).
Pastikan koneksi internet aktif saat pertama kali menjalankan proyek agar Maven mengunduh dependensi JavaFX dan SQLite JDBC.
Klik kanan pada proyek KatalogProduk > Run Maven > Goals..., ketik javafx:run, lalu klik OK (atau jalankan perintah mvn clean javafx:run melalui terminal di folder proyek).
